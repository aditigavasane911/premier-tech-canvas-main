# Premier Tech Canvas

## Tech Stack

- React · Node.js · MongoDB · Express · Java

## Development

Requirements: Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd premier-tech-canvas-main
npm install
npm run dev
```

## Build

```sh
npm run build
```
